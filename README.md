## ✨ Key Features

### 🎯 Core Requirements
1. **Firebase Firestore Integration:** Real-time NoSQL database for storing and managing user profiles and task submissions.
2. **Firebase Hosting:** Fast and secure deployment of the web app.
3. **Intern ID-based Search:** Interns can track their submission status securely using their Intern ID, Name, and Email.
4. **Admin Dashboard:** A secure admin panel to view all submissions and manage them (Approve/Reject) in real-time.
5. **Data Visualization:** Interactive charts (Doughnut & Bar) using `Chart.js` to display status breakdown and daily submission statistics.

### 🚀 Bonus Features Added
- **Role-based Authentication:** Secure login system that distinguishes between Admin and Intern roles.
- **Smart Auto-fill:** Interns' Name, Email, and ID automatically populate the submission form based on their profile, saving time while still allowing manual edits.
- **CSV Export:** Admin can download all submission data into a CSV file for offline record-keeping.
- **Task Categorization:** Added dropdowns for "Task Category" (e.g., Web Dev, UI/UX) and "Submission Round" (e.g., Week 1, Final Task).
- **Fully Responsive UI:** Clean, modern, and mobile-friendly design using custom CSS and FontAwesome icons.
